# 🏢 محاكي النظام المحاسبي المتكامل (Accounting OS Simulator)
### شركة النيل للتجارة والتوزيع • كود: NTL-2026

تطبيق ويب تفاعلي وتدريبي يحاكي الدورة المحاسبية السنوية الكاملة لشركة تجارية وفقاً لأحدث معايير المحاسبة المعتمدة (SOCPA / المعايير الدولية). تم تنظيم المشروع وفق بنية معمارية معيارية نظيفة (Modular Architecture).

---

## 🚀 طريقة التشغيل السريعة

1. **التشغيل المباشر:**
   - قم بفتح ملف `index.html` الموجود في المجلد الرئيسي مباشرة في أي متصفح (Chrome, Edge, Firefox).
   - سيقوم الملف بتحويلك تلقائياً وبسلاسة إلى لوحة التحكم الرئيسية (`dashboard/index.html`).

2. **عبر خادم محلي (اختياري - مثل Live Server):**
   - يمكنك فتح مجلد المشروع عبر VS Code وتشغيل إضافة **Live Server**.

---

│   └── index.html
│
├── bank-recon/index.html           # 3. التسوية والمطابقة البنكية (Bank Reconciliation)
│   └── index.html
│

│   └── index.html
│
└── accounts/index.html             # 6. شجرة الحسابات والدليل المحاسبي (Chart of Accounts)
    └── index.html

## 🖥️ الشاشات والوحدات البرمجية المرتبطة بها

| الشاشة | المسار | الوحدة البرمجية المسؤولة | الوظيفة |
| :--- | :--- | :--- | :--- |
| **نظرة عامة** | `dashboard/index.html` | `js/dashboard.js` | مؤشر الصحة المالية (82/100)، كشف فروقات الميزان، والوصول السريع. |
| **شجرة الحسابات** | `accounts/index.html` | `js/state.js` | الدليل المحاسبي الموحد للشركة يضم 20 حساباً مقسمة حسب طبيعتها. |
| **قيود اليومية** | `journal/index.html` | `js/journal.js` | مساحة عمل تفاعلية، معاينة المستندات المؤيدة، تفقيط المبالغ، والتحقق من القيد المزدوج. |
| **ميزان المراجعة** | `ledger/index.html` | `js/ledger.js` | ميزان المراجعة بالأرصدة وحسابات حرف T التفاعلية لدفتر الأستاذ العام، وخاصية الترحيل. |
| **القوائم المالية** | `statements/index.html` | `js/statements.js` | استخراج فوري لقائمة الدخل والميزانية العمومية المتوازنة. |
| **التسوية البنكية** | `bank-recon/index.html` | `js/recon.js` | مطابقة كشف الحساب البنكي الخارجي مع سجلات البنك الدفترية وإجراء التسويات آلياً أو يدوياً. |

---

## 💾 تخزين البيانات وإعادة التعيين

- يعتمد التطبيق على التخزين المحلي في المتصفح (`localStorage`) لحفظ تقدم المستخدم.
- لإعادة ضبط المحاكاة والبدء من جديد، يمكن الضغط على زر **"مسح الكل"** في شاشة اليومية أو استدعاء الدالة `resetSim()` من لوحة المطورين (Console).
